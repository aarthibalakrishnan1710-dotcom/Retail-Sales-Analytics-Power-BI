# Retail Sales Analytics — Power BI

An end-to-end retail sales analytics project using Python, MySQL, SQL and Power BI to clean, analyze and visualize 51K+ retail transactions.

## Tools & Technologies

- Python
- Pandas
- MySQL
- SQL
- Power BI
- DAX
- Power Query
- Advanced Excel

## Dataset

- 51,290 cleaned records
- 26 columns
- Data period: 2011–2014

## Key Metrics

- Total Sales: 12.64M
- Total Profit: 1.47M

## Analysis

The project analyzes:

- Sales and profit by category
- Sales and profit by region
- Yearly sales and profit trends
- Top 10 products by sales
- Sales by sub-category
- Customer segment performance

## Dashboard Features

- KPI cards
- Interactive slicers
- DAX measures
- Sales and profit analysis
- Product performance analysis
- Regional analysis
- Category and sub-category analysis

## Data Preparation

Python was used to clean and transform the retail dataset before loading the data into MySQL.

## SQL Analysis

SQL was used to analyze sales, profit, category performance, regional performance, product performance and yearly trends.

## Power BI

Power BI was used to build the interactive dashboard, create DAX measures, develop KPIs and visualize business insights.
